# Public edition provenance and release boundary

This edition was independently written in November 2026 to demonstrate general mathematical ideas in synthetic respiratory-waveform simulation and state assignment. A private application informed the requested conceptual scope only. Its implementation, records, outputs, trained models, internal configurations, documentation, screenshots and draft research material are not redistributed.

## Included

- Newly written mathematical model, browser interface, tests and English documentation.
- Fixed, invented parameter defaults and synthetic-only CSV export.
- Local assets with no runtime package dependency, external calls, recording import, telemetry or persistent browser storage.
- An explicit public-file allowlist and a synthetic-only CI workflow.

## Excluded

Clinical recordings, medical images, operational logs, identifying metadata, institutional or employer information, credentials, internal paths, professional source archives, private research results and equipment-specific configurations. No private application is loaded or executed. There is no input path through which the published browser demonstration can import clinical material.

The synthetic outputs do not preserve or imitate a specific confidential recording, operational distribution or calibration. Generic units and invented controls must not be mistaken for real hardware settings.

## Release review

The exact candidate files are listed in `PUBLICATION_ALLOWLIST.txt`. Before an external release, inspect the complete candidate, allowlist, staged content, Git history, proposed repository and visibility. Local tests are not publication approval. Approval must cover the exact reviewed files and commit; material changes require a new review.

Original private sources remain unchanged and outside this candidate. The existing repository history is retained; no private source archive or private Git history is imported. The MIT license applies to this independently written edition only and does not grant rights to any other project, source, data or research material.

If a possible disclosure is found, stop publication, avoid repeating sensitive values and preserve necessary evidence privately. Deleting a current file alone does not remove historical commits or prior copies; history changes require separate approval.
