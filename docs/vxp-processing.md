# VXP processing methods

This module independently implements a limited text-reader subset and general
numerical processing. It does not reuse a professional parser or algorithm.

## Public format reference

Varian Medical Systems, *Respiratory Gating for Scanners Instructions for Use*,
Appendix A, printed pages 63-64, "Export File Structure and Format":
[publicly accessible manufacturer manual copy](https://device.report/m/bc213f2c65beabdfeb7ac1f673a9eb2dc20586f58fc4d4c98849ed787b068e52).
The available document is marked as a draft. It is a format reference, not a
current compatibility certification. The manual is not bundled, and its example
identifiers, dates, waveform values, and recording configurations are not reused.
No third-party parser code is included. Vendor trademarks identify the format
only; no affiliation or endorsement is claimed. The MIT license covers this
repository's implementation, not the referenced manual or vendor products.

The independently written reader supports a seven-column Version 1.6 subset.
It locates sections instead of assuming fixed header line numbers, resolves
columns from `Data_layout`, and accepts reordered columns. Public table labels
with underscores and the documented short labels are recognized. Unknown
versions, missing/duplicate columns, and extra columns are rejected.

## Methods and behavior

| Method | Behavior |
| --- | --- |
| `parse_vxp(text)` | Validate text and numeric rows; discard header identifiers and dates |
| `read_vxp(path)` | Read one explicitly selected, bounded local UTF-8 file |
| Relative timing | Subtract the first timestamp and convert milliseconds to seconds |
| Amplitude scaling | Multiply the amplitude by the declared positive scale factor to obtain millimeters |
| Validity handling | Treat zero flags as valid and negative integer flags as invalid |
| `smooth_valid(trace, width=3)` | Centered moving average on separate contiguous valid segments |
| `window_features(trace, window_seconds=1)` | Valid-only mean, population standard deviation, range, and adjacent differences |

Phase, mark, and digital columns are structurally checked, then discarded.
Processing does not return a raw header dictionary, absolute timestamp, subject
identifier, acquisition date, or operational digital trace. Errors do not echo
filenames, header values, source lines, or malformed fields.

Smoothing and adjacent differences never bridge invalid samples or gaps longer
than 1.5 nominal sample intervals. This is an arbitrary teaching continuity rule.
No resampling, interpolation, checksum validation, phase recalculation, peak
classification, gating decisions, or clinical state assignment is performed.
The declared rate is not a guarantee of actual timing. Windows use relative
timestamps; absent windows are omitted, and partial windows retain their counts.
Statistics use valid observations only; all-invalid windows report `n/a`.
These methods are general arithmetic; no clinical thresholds are encoded.

Only UTF-8 text, at most 2,000,000 bytes/characters, 20,000 data rows, and
4,096 characters per nonblank line are accepted. These are invented software
resource limits, not device or clinical specifications. Converted values must
be finite; timestamps must be nonnegative and strictly increasing. CRC headers
are ignored, so this parser cannot establish file integrity or authenticity.
The synthetic fixture omits CRC and is not intended for import into equipment.

## Try the invented examples

```sh
python -m signal_demo
python -m signal_demo --vxp-demo
python -m signal_demo --vxp examples/synthetic.vxp
python -m unittest discover -s tests -v
```

The first command retains the dimensionless state-label demonstration. The
remaining commands demonstrate VXP numeric processing, without assigning those
toy state thresholds to a physical waveform. The fixture and its summary are
fully invented and generated by `synthetic_vxp_text()`; the fixture includes a
short invented invalid block to demonstrate quality handling.

The local-reader API is available for separately authorized work. This release
has been exercised only with invented inputs. No original files were processed
by this implementation, and no real-device compatibility has been established.

## Confidentiality boundary

**Discarding metadata does not anonymize a waveform.** Numeric samples, timing,
summaries, and combinations of features can still be confidential or identifying.
The local CLI prints numeric summaries. Use only approved inputs and keep their
outputs private unless separately reviewed. Never add local recordings to this
repository, packages, CI, examples, screenshots, or issue reports.

The repository contains no clinical data, trained model, production connection,
private format extension, or proprietary processing routine. Original code reuse
requires separate authorization and review. This educational subset cannot be
used to infer clinical validity or complete VXP compatibility.
